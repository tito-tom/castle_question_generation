2. Use correct JSON syntax, including commas between fields.

4. Describe only what is visible in the video.
5. Do not guess identities, intentions, or motivations.
6. Label people as person_1, person_2, etc.
7. Keep person labels consistent throughout the clip.
8. Identify important visible objects and actions.
9. Extract at most 5 distinct, meaningful events.
10. Do not generate repetitive or vague events such as

12. Use approximate timestamps only when supported by

13. For events, end_seconds must be greater than
    start_seconds.
14. If no specific event is identifiable, return

15. Do not generate questions yet.

Return EXACTLY these JSON fields:

  "participants": [
    "person_1"
  ],
  "objects": [
    "object_name"
  ],
  "events": [

The example values illustrate JSON formatting only.
Replace them with actual observations from the video.
Ensure the entire output is valid and complete JSON.


EVENT EXTRACTION RULES:

For every event, identify these components:

1. actor:
   The person performing the action.
   Example: "person_1"

2. action:
   A short, normalized action verb or verb phrase.
   Do not include the object or location in this field.
   Examples:
   - "retrieves"
   - "picks up"
   - "places"
   - "opens"
   - "cuts"
   - "pours"
   - "hands over"

3. object:
   The object being manipulated or affected by the action.
   Examples:
   - "drink"
   - "knife"
   - "cup"
   - "plate"
   - "bottle"

4. target:
   The secondary person, object, or location involved
   in the action, including a source or destination.

   Examples:
   - "fridge"
   - "table"
   - "person_2"
   - "sink"

5. description:
   A complete, factual sentence describing the event.

IMPORTANT:
- Extract structured fields from observable actions.
- Do not put the whole action description in the action field.
- If an object is clearly involved, put it in the object field.
- If a secondary location or participant is clearly involved,
  put it in the target field.
- Use null only when information cannot be reliably determined.
- Never invent objects, actions, or relationships.
- Return valid JSON only.
